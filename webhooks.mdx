## Introduction to Webhooks

Webhooks in Thomas Documentation allow you to receive real-time notifications about events in your documentation spaces. This enables automation and integration with other tools, keeping your workflows synchronized.

<Steps>
  <Step title="Create Webhook" icon="plus">
    Set up a new webhook endpoint in your space settings.
  </Step>
  <Step title="Configure Events" icon="settings">
    Choose which events should trigger the webhook.
  </Step>
  <Step title="Test Integration" icon="check">
    Send a test payload to verify your endpoint works.
  </Step>
</Steps>

## Setting Up Webhooks

Configure webhooks through the Thomas Documentation dashboard or API to start receiving event notifications.

<ParamField body="url" param-type="string" required="true">
  The endpoint URL to receive webhook payloads.
</ParamField>

<ParamField body="events" param-type="array" required="true">
  Array of event types to subscribe to.
</ParamField>

<ParamField body="secret" param-type="string" required="false">
  Optional secret for verifying webhook authenticity.
</ParamField>

```javascript
const webhookData = {
  url: 'https://api.example.com/webhooks/thomasdocs',
  events: ['doc.created', 'doc.updated'],
  secret: 'your_webhook_secret'
};

const response = await fetch('https://api.thomasdocs.com/webhooks', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify(webhookData)
});
```

<Expandable title="Webhook Security" default-open="false">
  Always use HTTPS for webhook URLs and implement signature verification using the provided secret. This ensures that incoming requests are genuine and haven't been tampered with.
</Expandable>

## Troubleshooting

Common issues and solutions for webhook setup.

- Verify your endpoint is accessible and returns a 200 status code
- Check that your server can handle the JSON payload format
- Ensure the webhook secret is correctly configured for signature verification
- Monitor webhook delivery logs in the Thomas Documentation dashboard

By leveraging webhooks, you can create a more dynamic and integrated documentation system that responds to changes in real-time.
