## Release History

<Update label="2024-10-15" description="v2.1.0" tags={["feature", "improvement"]}>

## New Features

- Added support for custom domains with SSL certificates
- Introduced advanced search with filters and sorting
- Implemented real-time collaboration for team editing

## Improvements

- Enhanced API performance with caching improvements
- Updated user interface for better mobile responsiveness
- Improved error handling and user feedback messages

</Update>

<Update label="2024-09-20" description="v2.0.0" tags={["breaking", "feature"]}>

## New Features

- Launched new API with GraphQL support
- Added webhook integrations for automation
- Introduced role-based access control

## Breaking Changes

- Updated authentication flow requiring re-login
- Changed API endpoints for better REST compliance
- Removed deprecated CSV import feature

</Update>
