## Space Settings

Each documentation space can be customized with specific settings, including themes, branding, and access controls. You can set default templates and configure how content is organized.

<Steps>
  <Step title="Create Space" icon="plus">

  </Step>
  <Step title="Set Properties" icon="settings">
    Configure name, description, and visibility settings.
  </Step>
  <Step title="Customize Theme" icon="palette">
    Choose colors and branding to match your organization.
  </Step>
  <Step title="Add Members" icon="user-plus">
    Invite team members and assign roles.
  </Step>
</Steps>

```javascript
const spaceConfig = {
  name: 'Project Docs',
  description: 'Documentation for our main project',
  theme: {
    primaryColor: '#3B82F6',
    fontFamily: 'Inter'
  },
  permissions: {
    public: false,
    roles: ['admin', 'editor', 'viewer']
  }
};
```

## User Management

Manage your team effectively with role-based permissions and user groups. You can create custom roles if the default ones don't fit your needs.

<ParamField body="userId" param-type="string" required="true">
  Unique identifier for the user.
</ParamField>

<ParamField body="role" param-type="string" required="true">
  Role to assign: admin, editor, or viewer.
</ParamField>

```python
import requests

user_data = {
  'userId': 'user123',
  'role': 'editor'
}
response = requests.post('https://api.thomasdocs.com/users', json=user_data)
print('User added:', response.json())
```

<Expandable title="Custom Roles" default-open="false">
  For advanced organizations, create custom roles with specific permissions. For example, you might have a 'Reviewer' role that can comment but not edit, or a 'Publisher' role that can only publish approved content.
</Expandable>

## Best Practices

Follow these guidelines to maintain an organized and efficient documentation setup.

- Regularly review and update user permissions
- Use consistent naming conventions for spaces and documents
- Set up automated backups for critical documentation
- Monitor usage analytics to optimize your configuration

With these configuration options, Thomas Documentation adapts to your specific needs, whether you're a small team or a large enterprise.
